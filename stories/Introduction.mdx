# Admin Dashboard UI Kit

Bu modern admin dashboard UI kit **TypeScript**, **Tailwind CSS** ve **Next.js** kullanılarak geliştirilmiştir.

## Özellikler

- **Reusable Components**: Tekrar kullanılabilir, esnek komponentler
- **Themeable**: Kolay tema özelleştirmesi
- **TypeScript**: Tip güvenliği
- **Responsive**: Mobil uyumlu tasarım
- **Accessible**: Erişilebilirlik standartlarına uygun
- **Modern Design**: Güncel UI/UX tasarım prensipleri

## Komponent Kategorileri

### UI Components

Temel kullanıcı arayüzü komponentleri:

- **Button**: Çeşitli stil ve boyutlarda butonlar
- **Input**: Form giriş alanları
- **Card**: İçerik kartları
- **Badge**: Durum ve kategori göstergeleri

### Dashboard Components

Dashboard spesifik komponentler:

- **StatCard**: İstatistik kartları
- **PaymentHistoryTable**: Ödeme geçmişi tablosu
- **Sidebar**: Navigasyon yan menüsü

### Forms

Form komponentleri ve örnekleri:

- **LoginForm**: Giriş formu örneği

## Tasarım Sistemi

### Renkler

- **Primary**: Mavi ton skala (indigo)
- **Secondary**: Gri ton skala
- **Accent**: Kırmızı/turuncu ton skala
- **Success**: Yeşil
- **Warning**: Sarı
- **Error**: Kırmızı

### Typography

- **Font Family**: Inter
- **Sizes**: text-xs, text-sm, text-base, text-lg, text-xl, text-2xl, text-3xl

### Spacing

Tailwind CSS spacing sistemi kullanılmaktadır (4px grid system).

## Kullanım

Her komponent, props ve kullanım örnekleri ile birlikte dokümante edilmiştir. Sol menüden ilgili komponenti seçerek detayları inceleyebilirsiniz.

```tsx
import { Button } from "@/components/ui/Button";
import { Input } from "@/components/ui/Input";
import { Card } from "@/components/ui/Card";

export function MyComponent() {
  return (
    <Card>
      <Input placeholder="Enter text..." />
      <Button>Submit</Button>
    </Card>
  );
}
```

## Geliştirme

Bu UI kit, modern web geliştirme araçları ve best practice'ler kullanılarak geliştirilmiştir:

- **Next.js 14**: React framework

- **Tailwind CSS**: Utility-first CSS
