# Typography

## Font Family

Projemizde **Inter** font ailesini kullanıyoruz:

```css
font-family: Inter, system-ui, -apple-system, sans-serif;
```

## Usage Guidelines

### Heading Hierarchy
- Sayfada sadece bir H1 kullanın
- Başlık hiyerarşisini atlamayın (H1 → H3 değil, H1 → H2)
- Her başlık seviyesi için tutarlı stil kullanın

### Text Colors
- `text-secondary-900` - Ana metin (en yüksek kontrast)
- `text-secondary-700` - İkincil metin 
- `text-secondary-600` - Yardımcı metin
- `text-secondary-500` - Placeholder ve disabled text

### Font Weights
- `font-normal (400)` - Normal metin
- `font-medium (500)` - Hafif vurgu
- `font-semibold (600)` - Orta vurgu  
- `font-bold (700)` - Güçlü vurgu

## Code Examples

```tsx
// Başlık örneği
<h1 className="text-3xl font-bold text-secondary-900">
  Dashboard Overview
</h1>

// Paragraf örneği
<p className="text-base text-secondary-700">
  Lorem ipsum dolor sit amet consectetur.
</p>

// Küçük metin örneği
<span className="text-xs text-secondary-500">
  Last updated 5 minutes ago
</span>
```
