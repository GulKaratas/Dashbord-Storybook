## Common Spacing Patterns

### Component Internal Spacing
- **Button Padding**: `px-4 py-2` (16px horizontal, 8px vertical)
- **Card Padding**: `p-6` (24px all sides)
- **Input Padding**: `px-3 py-2` (12px horizontal, 8px vertical)

### Layout Spacing
- **Section Gaps**: `space-y-6` (24px vertical)
- **Component Gaps**: `gap-4` (16px between items)
- **Grid Gaps**: `gap-6` (24px in grids)

### Margin Guidelines
- **Page Margins**: `p-6` (24px all sides)
- **Section Margins**: `mb-8` (32px bottom)
- **Element Margins**: `mb-4` (16px bottom)

## Layout Patterns

### Container Widths
```tsx
// Maximum content width
<div className="max-w-7xl mx-auto px-6">
  
// Card container
<div className="max-w-md mx-auto">

// Form container  
<div className="max-w-lg mx-auto">
```

### Flexbox Patterns
```tsx
// Horizontal layout with gap
<div className="flex items-center gap-4">

// Space between items
<div className="flex items-center justify-between">

// Vertical stack
<div className="flex flex-col space-y-4">

// Responsive flex
<div className="flex flex-col md:flex-row gap-4">
```

### Grid Patterns
```tsx
// Responsive grid
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">

// Auto-fit grid
<div className="grid grid-cols-auto-fit gap-4">

// Dashboard grid
<div className="grid grid-cols-1 md:grid-cols-4 gap-6">
```

## Breakpoints

Responsive tasarım için Tailwind breakpoint'leri:

- **sm**: 640px (mobile landscape)
- **md**: 768px (tablet)  
- **lg**: 1024px (laptop)
- **xl**: 1280px (desktop)
- **2xl**: 1536px (large desktop)
